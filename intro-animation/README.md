# MatchDocket — Canyon of Clarity intro

Editable 18-second Remotion composition, 1920 × 1080 at 60 fps. The second refined canyon visual is the selected reference. The interface is live vector/HTML markup, not flattened text in an image.

Preview: `npm install` then `npm run dev -- --no-open`. Select `MatchDocket-Canyon-Intro` in Studio. Current local preview: http://localhost:3000/MatchDocket-Canyon-Intro

Timing:
- 0–3 seconds: establish canyon, brand, opening statement.
- 3–6 seconds: invoice, purchase order and receipt arrive sequentially; connections resolve into the review desk.
- 6–11 seconds: compare sources, build zero-baseline variance waterfall, reveal $600 hold.
- 11–15 seconds: approach controller review; landscape softens to focus attention on the software.
- 15–18 seconds: pull back to the final headline, Clear evidence. Human control.

Silent by design for a website entry sequence. The project has not yet been rendered to MP4 or embedded in the public site. All records are explicitly synthetic. Review stays pending; no approval, payment or bank/ERP action is represented.

Finance invariant: INV-418 100 × $104 = $10,400; PO-772 100 × $100 = $10,000; GR-09 98 received; supported comparison $9,800; disputed $600 = $400 price + $200 quantity. Supported comparison does not authorize partial payment.

The canyon is a generated photographic plate with animated framing and lens focus; UI panels have separate perspective movement. This is a composited camera sequence, not physically simulated terrain or generated live-action footage.
