Supplier-change edge case

No shortcut around a bank hold.

A new bank-detail request creates a separate verification task. It must use an independently established contact route; replying to the same request is not the verification step.

The demo holds the request and shows a pending callback. It does not edit a vendor master or claim that a supplier is verified.

Hard hold · human-owned follow-up

Keep the decision history.

Reasons, source references and timestamps remain visible. An override preserves the earlier proposal and requires a recorded reason.

Agree access before a pilot.

Confidential data, ERP permissions, retention and security requirements need an agreed pilot plan. No certifications or production security posture are claimed here.

Keep execution out of the preview.

No funds transfer, outbound send, ERP write, bank update, filing or tax determination can be executed through the demo.
